# Upri5e portfolio

A responsive, static portfolio made with HTML, CSS, and JavaScript. No build or package installation is required.

## Local development

From this repository, run:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

## Make it yours

- Edit `index.html` to add your name, introduction, skills, and contact details.
- Add screenshots, gameplay footage, and a verified project link for PlasticBattlegrounds VR. The current project illustration is abstract artwork, not a gameplay screenshot. Add further project sections as you provide their details.
- Adjust colors and layout in `styles.css`.
- The GitHub contact link currently points to `https://github.com/Upri5e`.

Fonts load from Google Fonts, with local sans-serif fallbacks when offline.

## GitHub Pages

After committing and pushing the files to GitHub, select the branch containing the site and `/ (root)` in **Settings → Pages → Deploy from a branch**. The site requires no build step.
