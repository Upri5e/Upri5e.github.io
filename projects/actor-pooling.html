Overview

Actors ready when gameplay needs them.

I’m developing a C++ actor pooling plugin for Unreal Engine. The current implementation includes an option to pre-spawn a specified number of actors. The plugin is a work in progress, with replication planned and a release on Fab coming soon.

01

Configurable pre-spawning

The plugin can pre-spawn a developer-specified number of actors, allowing the initial pool size to be configured for the project.

02

Next steps

Replication support is planned and has not yet been implemented. The plugin is being developed towards a release on Fab.
