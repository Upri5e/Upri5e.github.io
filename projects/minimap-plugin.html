Overview

World information. In world.

I built a C++ Unreal Engine minimap plugin for diegetic map displays. The architecture separates world management, capture cameras, display actors and widgets, with Blueprint children for configuration.

01

Subsystem architecture

A world subsystem manages map cameras, points of interest, display actors and widgets. This supports multiple map displays without tying the entire system to a single player or actor.

02

Points of interest

A dedicated component describes each point of interest. The map widget converts map coordinates into pixel positions using its draw size and controls icon appearance and visibility.

03

Routes and occlusion

Spline points are cached in map space for route rendering. Routes support simple lines or material-based strips, configurable thickness and colour, and optional occlusion that splits the rendered path into visible sections.
